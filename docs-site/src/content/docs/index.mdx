"Oyla" means "vote!" in Turkish. It covers what you would use Mentimeter or Slido for in a small
room: no accounts, no app to install, no subscription. One Node.js process and one SQLite file run
the whole thing, so you can host it yourself with a single Docker container.

## What you get

<CardGrid>
  <Card title="Four question types" icon="list-format">
    Multiple choice, word cloud, open question and scale. Each one has its own editor, phone form
    and live results view.
  </Card>
  <Card title="Join with a code" icon="phone">
    Participants open the site and type a 6-digit code, or scan the QR code on the screen. No
    sign-up, no names.
  </Card>
  <Card title="Built for projectors" icon="laptop">
    Large type, high contrast, keyboard navigation and full screen. Light and dark mode follow the
    system setting.
  </Card>
  <Card title="No accounts" icon="padlock">
    Creating a presentation gives you a private admin link. Server owners can require a password
    for creating presentations.
  </Card>
  <Card title="English and Turkish" icon="translate">
    The interface follows the browser language and has a switch on every page.
  </Card>
  <Card title="Easy to extend" icon="puzzle">
    A question type is one shared definition plus three React components. MIT licensed.
  </Card>
</CardGrid>
