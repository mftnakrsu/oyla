## What Oyla does

"Oyla" means "vote!" in Turkish. You ask a question, everyone in the room answers from their
phone, and the results build up on the big screen. It covers what you would use Mentimeter or Slido
for, without accounts, an app to install or a subscription.

## Run it yourself

Oyla is software you run on your own computer or server. There is no hosted Oyla service to sign
up for: your presentations and your audience's answers stay on a machine you control.

With Docker, clone the repository, build the image and start a container:

```bash
git clone https://github.com/mftnakrsu/oyla.git
cd oyla
docker build -t oyla .
docker run -d --name oyla -p 3000:3000 -v oyla-data:/data oyla
```

Open [http://localhost:3000](http://localhost:3000) and create your first presentation.
Everything is stored in the `oyla-data` volume. For phones to join, they need to reach the server,
either on the same network or over the internet with HTTPS.
