## Oyla neler yapıyor

Adı üstünde: Oyla. Bir soru sorarsınız, salondaki herkes telefonundan cevap verir ve sonuçlar büyük
ekranda canlı olarak belirir. Mentimeter ya da Slido'yu ne için kullanıyorsanız Oyla da onun için
var; üstelik hesap, uygulama ya da abonelik istemez.

## Kendiniz çalıştırın

Oyla, kendi bilgisayarınızda ya da sunucunuzda çalıştırdığınız bir yazılım. Üye olabileceğiniz
hazır bir Oyla servisi yok; sunumlarınız ve katılımcıların cevapları sizin yönettiğiniz makinede
kalır.

Docker ile depoyu indirin, imajı derleyin ve bir konteyner başlatın:

```bash
git clone https://github.com/mftnakrsu/oyla.git
cd oyla
docker build -t oyla .
docker run -d --name oyla -p 3000:3000 -v oyla-data:/data oyla
```

Ardından [http://localhost:3000](http://localhost:3000) adresini açın ve ilk sunumunuzu
oluşturun. Bütün veriler `oyla-data` volume'unda saklanır. Telefonların katılabilmesi için
sunucuya erişebilmeleri gerekir: ya aynı ağdan ya da HTTPS üzerinden internetten.
